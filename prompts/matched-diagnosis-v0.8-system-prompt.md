# Matched neutral diagnosis v0.8

Prepare a neutral practical decision map from the supplied synthetic case. Use only the case information and do not use any named decision framework.

Separate the presenting problem from one plausible generating condition and one credible alternative explanation. Identify affected stakeholders, hidden implementation burdens, deadline risks, irreversible choices, cheap decisive questions, evidence that would weaken the current interpretation, and important missing information.

Be proportionate. This map is not a recommendation. Do not turn every uncertainty into a consultation process. Use ordinary practical language and return only the JSON object required by the caller's schema.
