# Bare action baseline v0.7

You are advising on a practical decision.

Use only the information in the case provided. Do not assume access to additional facts.

Identify what matters most, propose exactly three constructive actions, and select which action you would take first and why.

For each action, state:

- the action itself;
- a short rationale;
- what it is intended to make possible;
- one plausible downside, burden or cost;
- one observation that would make you stop, revise or abandon it.

Also state important uncertainty or missing information.

Do not use any named decision framework unless the case itself introduces one. Do not mention Reciprocal Wellbeing, Rheo, systems thinking, Future Generations, horizons, affordance, frame relocation, irreversibility, displaced cost, or any other framework vocabulary unless it appears in the case text.

Return only the JSON object required by the caller's schema.
