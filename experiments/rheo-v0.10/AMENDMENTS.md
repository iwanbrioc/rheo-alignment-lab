## 2026-09-16: primary evidence by reference

The first live A probe failed strict validation because duplicated primary-hypothesis fields did not match the generating-restriction copy. No options were accepted or presented. Replace duplicate fields with a checked hypothesis ID: triplet, evidence, confidence and falsifier belong to one immutable hypothesis record. This is a representation/validation correction, not evidence of improved causal reasoning. The original prospective mechanism predictions remain unchanged. Initial probe failures must be reported separately from later checks.

The first complete eight-case run accepted zero outputs: A-E/G failed duplicate-primary equality; F assigned high confidence to an AI-inferred observation; H used an unknown source reference. Before a second run, also constrain provider output sourceRefs to the supplied source IDs and prevent high-confidence AI-inferred observations in the generation schema. Runtime checks remain in place. Rejected synthetic outputs are retained by the probe runner for review, never sent to the mobile client. No claims of comparative effectiveness follow from these repairs.

The second run exposed an implementation error: structuredClone preserved shared schema-node references, so constraining sourceRefs also incorrectly constrained evidenceRefs to source IDs. Replace that clone with JSON serialization (schemas are JSON data) and add a regression assertion that evidence IDs remain independent of source IDs. Rejected outputs were not accepted as evidence. Re-run after this correction.

The third run exposed redundant action classification and over-restrictive prediction links. A prediction may legitimately compare a hypothesis other than the action's main hypothesisIds, so validate it against the full map instead. Replace model-declared causal target with server-derived same/different/unresolved horizon comparison; this is explicitly not a claim of repairing the cause. Keep the actual action triplet and system-change requirement. Add a generation-schema minimum of two observations for the learning option (two signals of one hypothesis are allowed for simple cases). Strengthen the prompt against non-learning wording exercises and dependence on another option. These are further development corrections, not an independent evaluation success.

Strengthen the plain-language constraints on first-action distinctness, independent starts, low confidence for unexplained motives and monitored-device safety. Use medium reasoning for this more demanding experimental contract, with an explicit environment override, and rerun. Do not present structural acceptance as semantic success or hide these failures.
