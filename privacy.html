Privacy

Keep only what the decision actually needs.

These notes describe the privacy posture of the current rheocracy.org website and the Rheo mobile alpha while both are still in development.

Last updated: 5 September 2026

The website

This first version of rheocracy.org is a static informational website. Rheo does not add analytics, advertising, tracking pixels, account creation, newsletter forms or behavioural profiling to the site.

The hosting and network providers used to deliver the site may process ordinary connection data such as IP addresses, browser information and server logs as part of operating their infrastructure. Those systems are outside the page code itself.

The mobile alpha

The current Rheo alpha is being built as a local-first decision tool. It does not require an account and does not include cloud sync, background location tracking, movement history or an analytics SDK.

Decision sessions may be stored locally on the device so that a user can revisit or delete them. The product should make that local storage visible rather than implying that nothing is retained.

Location

Location is optional. Rheo must remain usable without granting location permission.

  • Location is requested only in the foreground when the user explicitly asks Rheo to look around them.
  • Location precision is reduced before it is used for local-context lookup.
  • Raw coordinates are not stored in the saved decision session.
  • Nearby results are presented as possibilities to check, not as endorsements or proof of availability, accessibility or suitability.

Requests to Rheo

To generate a response, the situation a user writes—and, where the user has chosen it, relevant local context—may be sent to the configured Rheo service. The service needs that information in order to produce decision support.

The alpha is not intended to collect personal information for advertising, user scoring or behavioural targeting.

What Rheo deliberately does not claim

Rheo does not claim that locally stored decision text is encrypted unless the underlying device or storage implementation actually provides that protection. It also does not describe approximate local results as verified merely because a provider returned them.

This page will change

Rheo is still an alpha. Before any public release that materially changes storage, hosting, accounts, telemetry, third-party services or data retention, this page should be updated to describe those changes in ordinary language.
